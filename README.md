# eCommerce Platform - System Design

A comprehensive system design for a scalable eCommerce platform built with Java.

## Project Structure

docs/
├── requirements/ # Functional & Non-Functional Requirements
├── architecture/ # System Architecture & Diagrams
├── database/ # Database Schema & Design
└── api/ # API Documentation
src/ # Java Implementation

## System Users

- **Customer** — Browses and purchases products
- **Seller** — Lists and manages products
- **Admin** — Manages platform and users
- **Shipping Provider** — Handles order delivery
- **Customer Support** — Handles disputes and inquiries
