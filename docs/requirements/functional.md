# Functional Requirements

## 1. Customer
- Can register and login to the platform
- Can edit profile information and change password
- Can browse products as guest or logged-in user
- Can filter products by category, price, seller, or custom criteria
- Can view product details, images, and specifications
- Can add/manage delivery addresses and set a default
- Can add products to cart from listing or detail page
- Can view and modify cart contents
- Can view daily, monthly, seasonal, and special offers
- Can add products to wishlist
- Can proceed to checkout and payment gateway
- Can receive email confirmation after purchase
- Can track shipment after handoff to shipping provider
- Can rate and review products after purchase
- Can view ratings and reviews for products and sellers
- Can rate sellers
- Can search for products or categories with advanced search
- Can request return for defective products

## 2. Seller
- Can register on the platform (pending admin approval)
- Can add, edit, and delete products with images
- Can set and update product pricing
- Can create offers and discounts on products
- Can receive notifications for new orders
- Can generate financial and tax reports by date range

## 3. Admin
- Can approve or reject seller registration requests
- Can freeze sellers who violate platform policies
- Can browse all products and sellers
- Can export reports in Excel or PDF format
